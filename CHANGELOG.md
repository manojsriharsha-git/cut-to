# Changelog

All notable changes to Cut To: are listed here, newest first.

## 1.0.0 — 2026-10-28

The first public release.

### Writing and pages
- A Final Draft–style editor: real US Letter pages, the Enter/Tab element flow, Ctrl+1–8 element shortcuts.
- SmartType, which predicts scene headings, characters and transitions and learns from your scripts.
- Final Draft page rules, with (MORE) / (CONT'D) when a speech splits across pages.
- PDF export, printing and a title page.
- Formatting, colours, images and links.
- 32 bundled open-licence fonts, adding your own fonts, and changing the script font.

### Writing comfort
- Find & Replace and Go To.
- A command palette and spelling as you type.
- Day / Night / Midnight themes, Focus Mode and typewriter scrolling.
- Writing goals and renaming a character everywhere.
- Smart paste, crash recovery and version history.

### Planning
- Index cards that reorder scenes.
- A Beat Board with flow lines, storylines and structure points.
- A scene ribbon, character profiles and a character lens.

### Rewrites
- ScriptNotes.
- Revision mode, with Final Draft's colour order and asterisks.
- Comparing and restoring versions.

### Production
- Locked scene numbers (A-numbers) and omitted scenes.
- Breakdown tagging and breakdown sheets.
- Shot lists and a stripboard.
- TV, multi-camera and stage play templates.

### Insights
- Dialogue and scene statistics, who talks to whom and screen time.
- Table Read with a voice per character.

### Files
- `.cut` (native), `.fdx` and Fountain.
- Word import and export.
- PDF, Celtx, Trelby, Highland and Fade In import.
- RTF and plain-text export.

### Fixes before release
- Pressing Ctrl+1, Ctrl+2, Ctrl+3 then Ctrl+4 no longer crashes the app.
- Page measurements no longer depend on font metrics that differ between Windows and Linux.
